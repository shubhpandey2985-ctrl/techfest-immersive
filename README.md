# Techfest — Immersive Landing Page

An experimental, cinematic landing page concept inspired by the energy, scale, and innovation of **Techfest, IIT Bombay**.

The project focuses on creating an engaging web experience through **2D parallax scrolling, layered imagery, typography, smooth transitions, and interactive UI** — without relying on 3D assets.

> **Scroll. Explore. Discover the future.**

---

## ✨ Overview

Techfest is one of India's largest science and technology festivals, bringing together students, innovators, researchers, entrepreneurs, and technology enthusiasts.

This project reimagines the Techfest digital experience as a visually immersive landing page rather than a conventional event website.

The experience is designed around a simple idea:

**Make scrolling feel like exploration.**

The page progressively introduces the visitor to Techfest through cinematic visual compositions, large editorial typography, interactive cards, statistics, competitions, workshops, speakers, and strong calls to action.

---

## 🎯 Project Goals

- Create a visually impressive Techfest landing page.
- Build a strong first impression through a cinematic hero section.
- Use parallax scrolling to create depth using 2D layers.
- Introduce smooth scroll-triggered animations and transitions.
- Create an editorial and futuristic visual language.
- Keep navigation simple and intuitive.
- Maintain responsive behavior across desktop, tablet, and mobile.
- Avoid dependency on 3D models or heavy 3D assets.
- Keep the project performant and maintainable.
